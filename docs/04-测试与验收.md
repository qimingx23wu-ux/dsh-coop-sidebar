# 04 · 测试与验收

> 监控过程组（Monitoring & Controlling）产物：测试策略、缺陷清单、验收步骤。

## 1. 测试策略（分三层）

| 层级 | 手段 | 覆盖 |
|---|---|---|
| 静态检查 | `node --check`（宿主 index.js / 客户端 client.js） | 语法有效性 |
| 单元/冒烟 | Node 脚本模拟：host apply 全链路、client bundle 加载与 apply | 服务提供、typert 注册、Remote 标记、词库解释、overview、$mount、样式注入、清理 |
| 集成验收 | `dsh --profile web --dump-config` + `curl` 服务端 | 组合行生效、bundle 可访问、boot manifest 含插件 |

## 2. 缺陷登记册

| ID | 严重度 | 描述 | 根因 | 版本修复 | 回归验证 |
|---|---|---|---|---|---|
| D1 | 高 | 客户端渲染崩溃 `w is not a function`，侧边栏让位 | `useSessions()` 未传选择器（SnapshotSelectorHook 契约） | v0.1.1 | `cordis_inspect_self`：renderFailure 清除，client running |
| D2 | 高 | 侧边栏随进程重启消失 | 动态插件进程本地性（平台限制） | v0.2.0 | 重启后 `curl` boot manifest 含 coop-sidebar，bundle 200 |
| D3 | 中 | 输入时面板遮挡、不自动收缩 | 面板常驻右下 fixed 定位，无聚焦联动 | v0.2.1 | 语法 + curl 服务端包含 focusin 处理器；待用户硬刷新后目测 |

## 3. 验收步骤（用户侧）

1. 打开 `http://127.0.0.1:3080`（改动后先 **⌘+Shift+R 硬刷新**——HMR 被部署禁用，必须绕过浏览器缓存）。
2. 右侧边缘出现「术语雷达」竖条 → 点击展开为面板。
3. **术语雷达**：点任意术语 → 5 秒内出现 5 段式解释；输入问题或点建议追问 → 回答更新。
4. **过程透明**：能看到当前会话、最近工具活动（绿/蓝/红点）、权限与沙箱、边界清单。
5. **协作之道**：五个角色 + 五种能力展示。
6. **自动收起**：点进下方输入框打字 → 面板自动收起；点面板内「继续追问」输入框 → 不收起。
7. **持久化**：刷新页面、重启 DSH → 侧边栏仍在。

## 4. 冒烟测试脚本速查

```bash
# 语法
node --check ~/.dsh/profiles/web/plugins/coop-sidebar/lib/index.js
node --check ~/.dsh/profiles/web/plugins/coop-sidebar/lib/client.js

# 宿主 apply 冒烟（服务提供 / typert 注册 / Remote 标记 / 词库解释）
cd ~/.dsh/profiles/web && node --input-type=module -e "
import('file://$PWD/node_modules/coop-sidebar/lib/index.js').then(async (m) => {
  const plugin = m.default
  const provided = {}
  const registered = []
  const fakeCtx = {
    reflect: { provide(n, v) { provided[n] = v } },
    get(k) { if (k === 'typert') return { register: (c) => { registered.push(c); return async () => {} } }; return undefined },
    provide(n, v) { provided[n] = v },
  }
  plugin.apply(fakeCtx)
  const svc = provided.coopSidebar
  const r = await svc.explain({ term: '沙箱', sessionId: '' })
  console.log('explain:', r.source, r.summary)
})"

# 客户端 bundle 加载冒烟（模拟 ModuleLoader + react 桩）
cd ~/.dsh/profiles/web && node -e "
const fs = require('fs')
const src = fs.readFileSync('plugins/coop-sidebar/lib/client.js', 'utf8')
let loaded = null
global.window = { __ModuleLoader__: { load: (x) => { loaded = x } } }
eval(src)
const mod = loaded.factory((s) => s === 'react' ? { createElement: () => ({}), useState: () => [], useEffect: () => {}, useCallback: () => {} } : (() => { throw new Error(s) })())
console.log('bundle:', loaded.id, '| inject:', mod.inject.join(','))
"
```
