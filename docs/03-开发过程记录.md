## 2. 关键事件记录

- **D1 渲染崩溃**：`useSessions` 是 `SnapshotSelectorHook<T> = <S>(sel) => S`，无参调用等价于把 `undefined` 当选择器 → React `useSyncExternalStore` 内部抛 `w is not a function`。修复：恒等选择器。
- **D2 进程重启**：动态插件定义在内存，进程重启即失。修复：静态部署插件。
- **D3 输入遮挡**：面板 `position:fixed` 常驻右下，遮挡 composer。修复：`focusin` 捕获监听，聚焦输入区自动收起，`el.closest('.coop-panel')` 排除自身输入框。
