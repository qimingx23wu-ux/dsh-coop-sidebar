# 08 · 产品路线图（Product Roadmap）

> 产品生命周期管理：优先级（MoSCoW）、版本规划、候选功能池。

## 1. MoSCoW 优先级

| 优先级 | 含义 | 功能项 |
|---|---|---|
| **M**ust（必须有） | 下一迭代必做 | 术语点击高亮对话原文；解释一键复制/导出笔记 |
| **S**hould（应该有） | 重要但有替代 | 词库用户可配置（增删术语/别名）；新术语出现角标动画提醒 |
| **C**ould（可以有） | 锦上添花 | 面板可拖拽、宽度记忆；协作之道长文阅读模式 |
| **W**on't（暂不做） | 明确排除 | 替换现有 UI；多用户实时协作 |

## 4. 迭代评审标准（Definition of Done）

一个迭代功能必须全部满足才算完成：
- [ ] 功能实现并通过语法/冒烟验证
- [ ] 版本号 + CHANGELOG + versions/ 归档已更新
- [ ] 用户按 `docs/04` 验收步骤确认通过
- [ ] 风险登记册与运维手册如有变化已同步
