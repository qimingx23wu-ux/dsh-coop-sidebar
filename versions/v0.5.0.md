# v0.5.0 · 词库可视化配置（在侧边栏内增删词条）

> 状态：✅ 代码就绪，**需重启 DSH 生效**（宿主半身新增远程方法）

## 变更内容
- **宿主**新增两个远程方法：
  - `writeGlossary`：`op:'add'`（校验后追加词条）/ `op:'delete'`（按 term 删除）→ **临时文件 + 原子 rename** 写入 `lib/glossary-extra.json`，失败回滚；重复添加/非法输入被拒绝并返回原因。
  - `glossaryList`：返回当前自定义词条（term/category/aliases）。
- **客户端**新增「词库」入口（面板底部按钮）→ 词库管理视图：
  - 展示自定义词条列表 + 逐个删除；
  - 新增词条表单（术语名称/别名必填，分类/5 段式/追问可选，逗号分隔解析）；
  - 增删后 5 秒内出现在术语雷达（复用热更新机制，无需刷新）。

## 影响评估（变更三问）
- 改哪端：**宿主 + 客户端** → **需重启 DSH 一次**；
- 风险：写入采用原子替换，失败不影响既有词库；内置 36 词不可删（仅扩展词库可操作）。
