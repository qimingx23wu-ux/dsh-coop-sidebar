# v0.4.0 · 术语点击高亮对话原文（定位）

> 状态：✅ 已交付（仅客户端变更，硬刷新生效，无需重启）

## 变更内容
- **F1 术语定位**：详情面板右上角新增「定位原文」按钮。点击后：
  - 用 DOM 文本节点遍历（跳过侧边栏自身）在当前页面对话中查找该术语（英文按词边界匹配，中文直接匹配）；
  - 用 `Range.getBoundingClientRect` 精确定位每一处出现，以**浮动高亮环**标注（最多 20 处）；
  - 自动滚动到第一处；2.5 秒后或滚动/缩放时自动清除；
  - **不修改任何 React 管理的 DOM**（只读文本 + 挂自己的高亮元素），对主对话渲染零侵入，卸载时清理。

## 技术取舍（调研结论）
- 会话节点快照（ConversationSnapshot）只提供给 **session 级槽位**，根作用域侧边栏拿不到 → 放弃"节点定位"路线；
- 改为**浏览器侧"查找并高亮"**方案：TreeWalker + Range，纯客户端、无宿主改动、无重启、低风险。

## 影响评估（变更三问）
- 改哪端：仅客户端 `lib/client.js` → **无需重启 DSH**；
- 用户获取：页面硬刷新（⌘+Shift+R）；
- 风险：低；DOM 结构变化只影响定位精确度（有兜底：无命中时静默），不崩溃。
