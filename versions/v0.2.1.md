# v0.2.1 · 输入聚焦自动收起

> 状态：✅ 已交付（当前版本）

## 背景
用户反馈：在下方输入框输入时，侧边栏面板遮挡输入，且不会自动收缩（缺陷 D3）。

## 变更内容
- 客户端 `lib/client.js` 新增「输入聚焦自动收起」：
  - `document.addEventListener('focusin', …, true)` 捕获阶段监听；
  - 焦点进入 `TEXTAREA` / `INPUT` / `[contenteditable]` 时自动 `setOpen(false)` 收起；
  - `el.closest('.coop-panel')` 排除侧边栏自身输入框（如「继续追问」），避免误收起；
  - `openRef` 镜像避免监听器闭包过期；卸载时移除监听（可逆副作用）。
- 版本号：插件 `package.json` `0.1.0 → 0.2.1`（与 CHANGELOG 对齐）。

## 影响评估
- 改哪端：仅客户端 bundle → **无需重启 DSH**；
- 用户获取：页面硬刷新（⌘+Shift+R）——HMR 被部署禁用，rev 不变时必须绕过浏览器缓存。

## 验证
- `node --check` 通过；`curl /plugins/coop-sidebar/client.js` 200 且内容含 focusin 处理器；
- 待用户硬刷新后按 `docs/04` 第 6 步验收。
