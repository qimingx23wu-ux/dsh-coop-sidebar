# v0.3.0 · 解释一键复制 / 导出笔记

> 状态：✅ 已交付（仅客户端变更，硬刷新生效，无需重启）

## 变更内容
- **F2 解释一键复制**：详情面板右上角新增「复制」按钮，点击将当前术语的完整 5 段式解释
  （总结/大白话/例子/原理/边界）复制到剪贴板；成功后按钮短暂变为「已复制 ✓」。
- **F3 导出合并**：复制即导出——复制内容即为可粘贴到任意笔记工具的格式化文本（按段落分隔）。
