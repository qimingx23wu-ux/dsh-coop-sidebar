# v0.2.0 · 静态部署版（持久化）

> 状态：✅ 已交付（部署级插件，重启不丢失）

## 背景
动态插件（v0.1.x）随 DSH 进程重启丢失（风险 R2 触发）。本版本为架构级变更：重写为**部署级静态插件**。

## 变更内容
- 新增 `~/.dsh/profiles/web/plugins/coop-sidebar/` 包：
  - 宿主半身 `lib/index.js`：`CoopSidebarService extends TypertRemoteService`（key `coopSidebar`），
    `overview`/`explain` 远程方法，`ctx.typert.register` 注册调用描述符；
    纯 JS 伪造装饰器上下文实现 `@Remote` 标记（`remoteMethods()` 验证通过）。
  - 客户端 bundle `lib/client.js`：手写 `__ModuleLoader__.load`，`ctx.remote.$mount` 挂载命名空间，
    `ctx.slots.inject('shell.overlay')` 注册侧边栏；`src-json` codec 免 schema 描述符。
- 组合挂载：`cordis.patch.yml` 增加 `- insert: coop-sidebar`；`pnpm-workspace.yaml` 增加 `plugins/*`；
  根 `package.json` 声明 `coop-sidebar: workspace:*` → node_modules 软链。

## 验证（全通过）
- `node --check` 两端语法；host apply 冒烟（服务提供/typert 注册/Remote 标记/词库解释/overview）；
- client bundle 模拟加载 + apply + 清理；`dsh --dump-config` 组合行生效；
- 重启后 `curl`：boot manifest 含 `coop-sidebar`、bundle 200。

## 文件变更
- 新增：`plugins/coop-sidebar/{package.json, lib/index.js, lib/client.js}`
- 修改：`cordis.patch.yml`、`pnpm-workspace.yaml`、根 `package.json`

## 发布说明
- 客户端 bundle 已随重启加载；HMR 被部署禁用 → 后续客户端改动需**硬刷新**（⌘+Shift+R）。
